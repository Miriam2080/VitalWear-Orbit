\# VitalWear Orbit



Aplicación desarrollada para la asignatura Desarrollo para Dispositivos Inteligentes.



\## Descripción



VitalWear Orbit es una solución entre Wear OS y Android Mobile que permite monitorear sensores del smartwatch, sincronizar datos con el teléfono, controlar la cámara del celular desde el reloj y enviar alertas SOS.



\## Funcionalidades



\- Lectura de sensores en Wear OS.

\- Sincronización de datos Wear a Mobile.

\- Secciones de salud, ambiente y movimiento.

\- Detección de movimiento mediante acelerómetro.

\- Cámara remota desde el reloj.

\- Galería de fotos en el móvil.

\- Registro de eventos.

\- Icono personalizado.
